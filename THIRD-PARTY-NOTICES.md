# Provenance and third-party notices

The distributed wrapper, test doubles, scripts and programmatically drawn icon
are presented as original project work. Owner confirmation of authorship and the
existing MIT license remains a release decision. No external library source,
vendored binary, package manager dependency or iPad receiver is included.

declarations and public build/framework UUID are interoperability information;
legal review must decide whether their publication is acceptable in the relevant
jurisdictions. This audit does not establish legal clearance.

FeatureUnlock and FeatureUnlock-Tahoe (BSD-3-Clause, with upstream notices).
None is built, copied or packaged as a project dependency. If code is imported
later, review its actual file license and attribution/copy-left obligations first.

code is caller-side ABI checking and API use, not a reproduced Apple algorithm.

Sidecar icon. The UI uses an installed SF Symbol through AppKit, without packaging
Apple artwork. Apple and product names belong to their respective trademark owner.
