# Hardware validation

## SideHustle 0.4.0

The user reports testing this build over wired and wireless connections and
improved wireless connection stability. Device model, OS versions, and test
procedure were not provided, so no additional compatibility claims are made.

## Historical physical test

An earlier build connected an iPad (5th generation) running iPadOS 16.7.16 to an
Apple silicon Mac and showed the Mac desktop on the iPad. This result predates
version 0.4.0 and does not establish compatibility with other device or OS
combinations.

Login item approval, startup connection, reboot persistence, every supported
macOS version, and the newly enabled iPad models still need separate testing.
